# ContextSail 2.25.0

ContextSail is a local-first AI browser workspace: collect web sources, organize them on an infinite canvas, and ask Codex or Claude Code with context.

- New ContextSail brand, sail icon, and repository name.
- Updated English and Chinese documentation, installation links, and release package names.
- Existing Chrome extension data and AI connections remain compatible. Legacy storage keys, Native Messaging IDs, and `shizuo_*` MCP tools are intentionally unchanged; they are technical compatibility identifiers, not the public brand.

Reload the unpacked extension in `chrome://extensions`. No uninstall, data reset, or MCP reinstallation is needed for existing users.
