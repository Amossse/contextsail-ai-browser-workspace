# ContextSail 2.26.0

The page assistant now includes a **Perspectives** shortcut beside Translate, Summarize, Analyze, and Explore ideas. It analyzes the current article, or an attached text selection, through five simulated viewpoints: practitioner, scholar, skeptic, economist, and historian.

Each perspective returns a two-sentence position, its strongest supporting evidence with traceable sources where available, and a distinct insight. The prompt distinguishes source claims from verified facts and inference, marks unavailable evidence, and prohibits invented citations. Results appear in the existing page conversation.

Both English and Simplified Chinese are supported. Reload the unpacked extension from `chrome://extensions`, then refresh the article tab to load the new shortcut. Existing conversations and collected content are unchanged.
